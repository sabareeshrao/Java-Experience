## Daily continuity rule

Before starting a new day:

1. Verify `main` and the latest remote commit.
2. Read the current project state rather than recreating files.
3. Check question coverage so completed questions are not counted again.
4. Select uncovered questions that naturally fit the day's engineering work.
5. Implement only the day's logical change.
6. Test and debug it.
7. Commit, push, and verify the remote SHA.
8. Hand that exact state to the next day.
