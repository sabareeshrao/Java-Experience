# Interview practice

## What is the difference between JDK, JRE and JVM?

For this early Java project, I use the JDK for development because it provides compiler tools such as `javac`. In the traditional Java 8 model, the JRE provides the runtime libraries and JVM required to run Java applications. The JVM is the execution engine that loads and executes compiled bytecode.

## Can a machine have multiple JDK or JRE versions installed?

Yes. A workstation can have multiple Java versions installed side by side. The active one depends on configuration such as IDE settings, `JAVA_HOME` and the executable resolved through PATH. That is why `java -version` and `javac -version` are useful troubleshooting checks.

## What is the JVM and how does it work?

The JVM loads compiled `.class` bytecode, verifies it, manages execution and runtime memory, and executes the instructions using a JVM implementation for the current platform. In this project we inspected the generated class using `javap` before running it.

## How does Java code execute?

`javac` compiles `.java` source into `.class` bytecode. The `java` launcher starts the JVM, loads the class and executes its bytecode beginning from the application entry point.
