# Java references vs explicit pointers

Java object variables can refer to objects, but Java source does not expose C/C++-style pointer arithmetic or explicit dereference operators. The reference abstraction plus managed memory reduces direct memory manipulation risks.

# Pass-by-value evidence

When a `SurveyProject` is passed to a method, Java copies the reference value. Both references can reach the same object, so mutation is visible to the caller. Reassigning the method parameter only changes that local copy.
