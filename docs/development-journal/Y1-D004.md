# Engineering problem

Operations still receives early survey-project estimates from spreadsheet-heavy tracking. Estimated records arrive as text such as `"12500"`, but calculations need an `int`. Completion percentages may contain decimals while the first console summary displays a whole percentage. Reports may need the numeric count converted back to text.

```text
"12500" -> int 12500
87.9 -> explicit cast -> int 87
12500 -> String "12500"
```

We also need one class-level count of successful intake parses.
